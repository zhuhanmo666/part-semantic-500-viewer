# GitHub Pages deployment

1. Create an empty public GitHub repository.
2. Push every file in this directory to its `main` branch.
3. In Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`.
4. Wait for the Pages URL to become active.

The bundle is close to GitHub Pages' 1 GB published-site limit. Do not add duplicate model copies or Git LFS pointers (Pages does not serve LFS objects as normal site files).
